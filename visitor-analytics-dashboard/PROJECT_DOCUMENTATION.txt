১. প্রজেক্টের সামগ্রিক আর্কিটেকচার (Overview)
================================================================================
এই প্রজেক্টটি একটি ফুল-স্ট্যাক ওয়েব অ্যাপ্লিকেশন যার দুটি মূল অংশ রয়েছে:

ক. পাবলিক ব্লগ ওয়েবসাইট (Frontend):
   - পাঠকরা ব্লগ পড়ে, সার্চ করে এবং বিভিন্ন পেজ ভিজিট করে।
   - প্রতিটি পেজ লোড হওয়ার সময় ব্যাকগ্রাউন্ডে সম্পূর্ণ গোপনে ইউজারের IP, 
     লোকেশন ও ব্রাউজারের তথ্য সংগ্রহ ও ডাটাবেসে সেভ হয় (ইউজার কোনো বিলম্ব বা বাধা টের পায় না)।

খ. অ্যাডমিন কন্ট্রোল প্যানেল ও থ্রেট শিল্ড (Backend):
   - অ্যানালিটিক্স ড্যাশবোর্ড: লাইভ ভিজিটর সংখ্যা, টপ দেশ, চার্ট এবং রিয়েল-টাইম বিশ্ব মানচিত্র।
   - ফায়ারওয়াল শিল্ড: সন্দেহজনক বা ক্ষতিকর আইপি ১-ক্লিকে ব্লক/ব্যান করা (ব্লকড ইউজার সাইটে ঢুকলে ৪০৩ দেখাবে)।
   - ব্লগ ম্যানেজার: নতুন আর্টিকেল তৈরি, এডিট, ডিলিট এবং পাঠক ভিউ মনিটর করা।


================================================================================
২. IP অ্যাড্রেস ট্র্যাকিং কীভাবে কাজ করে? (getUserIP Logic)
================================================================================
লোকেশন: includes/functions.php -> getUserIP()

কিভাবে কাজ করে:
একজন ইউজার যখন ওয়েবসাইটে ঢোকে, তার অনুরোধটি বিভিন্ন প্রক্সি (যেমন: Cloudflare, 
Load Balancer, VPN) অতিক্রম করে আসতে পারে। সঠিক IP পাওয়ার জন্য অগ্রাধিকার (Priority) তালিকা ব্যবহার করা হয়:

১. HTTP_CF_CONNECTING_IP:
   ইউজার যদি Cloudflare এর মাধ্যমে আসে, Cloudflare আসল আইপিটি এই হেডারে পাঠায়।
২. HTTP_X_FORWARDED_FOR:
   সাধারণ প্রক্সি বা লোড ব্যালেন্সার অতিক্রম করলে এই হেডারে আইপি থাকে (একাধিক আইপি থাকলে প্রথমটি নেওয়া হয়)।
৩. HTTP_CLIENT_IP:
   কিছু প্রক্সি সার্ভার এই হেডারে ক্লায়েন্টের আইপি পাঠায়।
৪. REMOTE_ADDR:
   ওয়েব সার্ভার সরাসরি যে আইপি থেকে কানেকশন পায়। এটি সবচেয়ে নির্ভরযোগ্য ও অপরিবর্তনযোগ্য।

নিরাপত্তা ফিল্টার:
`filter_var($ip, FILTER_VALIDATE_IP)` ব্যবহার করে নিশ্চিত করা হয় যে প্রাপ্ত মানটি একটি বৈধ IPv4 বা IPv6 অ্যাড্রেস।


================================================================================
৩. Geolocation API এবং ডাটাবেস ক্যাশিং সিস্টেম (getGeoData Logic)
================================================================================
লোকেশন: includes/functions.php -> getGeoData($pdo, $ip)

কেন এই ক্যাশিং দরকার?
ipinfo.io প্রতি মাসে ৫০,০০০ রিকোয়েস্ট ফ্রিতে দেয়। প্রতিটি পেজ লোডে যদি নতুন করে API কল করা হতো, 
তবে কয়েক দিনেই কোটা শেষ হয়ে যেত এবং পেজ লোড হতে অনেক বেশি সময় লাগত।

কাজের ধাপসমূহ:
----------------
ধাপ ১ (প্রাইভেট ও লোকালহোস্ট ফিল্টারিং):
`FILTER_FLAG_NO_PRIV_RANGE` দিয়ে লোকালহোস্ট/প্রাইভেট আইপির ক্ষেত্রে অপ্রয়োজনীয় API কল বন্ধ রাখা হয়। 
ডেভেলপমেন্ট মোডে এটি মেশিনের আসল আউটবাউন্ড ইন্টারনেট লোকেশন নির্ধারণ করে।

ধাপ ২ (ডাটাবেস ক্যাশ চেক):
সবার আগে `ip_geo_cache` টেবিলে চেক করা হয়:
"এই আইপির তথ্য কি গত ৩০ দিনের মধ্যে ডাটাবেসে সেভ করা হয়েছে?"
যদি পাওয়া যায়, সাথে সাথে ডাটাবেস থেকে তথ্য রিটার্ন করা হয় (কোনো API কল লাগে না, গতি: ০.০০১ সেকেন্ড)।

ধাপ ৩ (API কল - শুধুমাত্র নতুন আইপির জন্য):
যদি ক্যাশে ডেটা না থাকে, তবে ৩ সেকেন্ড টাইমআউট দিয়ে ipinfo.io API তে কল পাঠানো হয়:
URL: https://ipinfo.io/{ip}/json?token={token}

ধাপ ৪ (কোঅর্ডিনেট ও লোকেশন পার্সিং):
API এর রেসপন্স থেকে বের করা হয়:
- country (দেশ)
- city (শহর)
- region (বিভাগ/অঞ্চল)
- org (ISP বা ইন্টারনেট সেবাদাতা)
- loc (অক্ষাংশ ও দ্রাঘিমাংশ, যেমন: "23.8103,90.4125" -> latitude, longitude)

ধাপ ৫ (স্মার্ট আপসার্ট ক্যাশিং):
PostgreSQL এর `ON CONFLICT (ip_address) DO UPDATE` কুয়েরি দিয়ে তথ্যটি `ip_geo_cache` টেবিলে 
৩০ দিনের জন্য সংরক্ষণ করে রাখা হয়, যাতে ভবিষ্যতে একই ভিজিটর এলে আর API কল না লাগে।


================================================================================
৪. ফায়ারওয়াল ও রিয়েল-টাইম আইপি ব্লকিং সিস্টেম (Security Firewall)
================================================================================
লোকেশন: includes/functions.php ও includes/track.php

ফাংশনসমূহ:
- `isIpBlocked($pdo, $ip)`: কোনো আইপি ব্লকড তালিকায় আছে কিনা চেক করে।
- `blockIp($pdo, $ip, $reason)`: নতুন আইপিকে `blocked_ips` টেবিলে যুক্ত করে।
- `unblockIp($pdo, $ip)`: আইপিকে ব্লক তালিকা থেকে সরিয়ে দেয়।

কাজের প্রক্রিয়া:
১. ভিজিটর যখনই সাইটের যেকোনো পেজে প্রবেশ করে, `trackVisit()` সবার আগে `isIpBlocked()` কল করে।
২. যদি আইপিটি ডাটাবেসের `blocked_ips` টেবিলে থাকে:
   - সাথে সাথে সার্ভার `HTTP 403 Forbidden` স্ট্যাটাস কোড পাঠায়।
   - একটি ডার্ক থিমযুক্ত "403 Access Denied - Your IP is Blocked" সিকিউরিটি পেজ প্রদর্শন করে।
   - পিএইচপি স্ক্রিপ্ট `exit` করে বন্ধ হয়ে যায়, ফলে ভিজিটর ব্লগের কোনো কন্টেন্ট বা ডাটাবেস দেখতে পায় না।
৩. অ্যাডমিন ড্যাশবোর্ড থেকে যেকোনো সময় ১-ক্লিকে যেকোনো সন্দেহজনক আইপি ব্যান বা আনব্যান করা যায়।


================================================================================
৫. বট ও ক্রলার ডিটেকশন ইঞ্জিন (Bot Detection)
================================================================================
লোকেশন: includes/functions.php -> parseUserAgent($userAgent)

কেন এটি দরকার?
সার্চ ইঞ্জিন বট (যেমন: Googlebot, Bingbot) এবং অটোমেটেড হ্যাকিং স্ক্র্যাপাররা ওয়েবসাইটে প্রতিনিয়ত ভিজিট করে। 
এদের আসল মানুষের সাথে মিশিয়ে ফেললে অ্যানালিটিক্স রিপোর্ট ভুল দেখায়।

লজিক:
User-Agent স্ট্রিং বিশ্লেষণ করে নিম্নলিখিত প্যাটার্নগুলো শনাক্ত করা হয়:
- Googlebot -> Googlebot
- Bingbot -> Bingbot
- Slurp -> Yahoo Slurp
- DuckDuckBot -> DuckDuckBot
- Baiduspider / YandexBot -> Baidu / Yandex
- curl / python-requests / Postman -> Automated Scrapers / Tools

শনাক্ত হলে `is_bot = true` ফ্ল্যাগ দিয়ে ডাটাবেসে সেভ হয় এবং ড্যাশবোর্ডে "🤖 Bot" ব্যাজ সহ আলাদা পরিসংখ্যানে দেখানো হয়।


================================================================================
৬. লাইভ অ্যানালিটিক্স ড্যাশবোর্ড ও ইন্টারঅ্যাক্টিভ মানচিত্র
================================================================================
লোকেশন: admin/dashboard.php ও admin/api_live.php

মূল ফিচারসমূহ:
১. রিয়েল-টাইম অটো-রিফ্রেশ (AJAX Polling):
   - `api_live.php` একটি লাইটওয়েট JSON এন্ডপয়েন্ট।
   - ড্যাশবোর্ডের জাভাস্ক্রিপ্ট প্রতি ৮ সেকেন্ড পরপর ব্যাকগ্রাউন্ডে কল করে পেজ রিলোড ছাড়াই 
     লাইভ ভিজিটর সংখ্যা ও সময় আপডেট করে।
২. ওপেনস্ট্রিটম্যাপ ও লিফলেট (Leaflet.js World Map):
   - ডাটাবেস থেকে প্রাপ্ত Latitude ও Longitude অনুযায়ী পৃথিবীর মানচিত্রে লাল মার্কার পিন আঁকা হয়।
   - মার্কারে ক্লিক করলে শহর, দেশ, আইপি এবং মোট ভিজিট সংখ্যা পপ-আপে ভেসে ওঠে।
   - `map.fitBounds()` স্বয়ংক্রিয়ভাবে ভিজিটরদের লোকেশনে মানচিত্র জুম করে দেয়।
৩. চার্ট বিশ্লেষণ (Chart.js):
   - টপ ১০ দেশ (Bar Chart)
   - জনপ্রিয় পেজসমূহ (Doughnut Chart)
৪. ডার্ক ও লাইট মোড সুইচার:
   - ব্যবহারকারীর পছন্দ ব্রাউজারের `localStorage`-এ সেভ থাকে।
৫. CSV এক্সপোর্ট:
   - `fputcsv()` ফাংশন ব্যবহার করে ১-ক্লিকেই সম্পূর্ণ ভিজিটর রিপোর্ট Excel/CSV ফাইলে ডাউনলোড হয়।

৭. ফুল-ফিচার্ড ব্লগ ম্যানেজমেন্ট সিস্টেম (Blog Engine)
================================================================================
লোকেশন: public/ (Frontend) ও admin/ (Backend)

ফিচারসমূহ:
১. হোমপেজ (`public/index.php`):
   - হিরো ব্যানার, লেটেস্ট পোস্ট গ্রিড, ক্যাটাগরি পিলস ও লাইভ সার্চ বার।
২. অল আর্টিকেল আর্কাইভ (`public/blog.php`):
   - ক্যাটাগরি এবং কি-ওয়ার্ড সার্চিং ফিল্টার (`ILIKE %search%`)।
৩. পোস্ট রিডার (`public/post.php`):
   - আর্টিকেল ওপেন হলে স্বয়ংক্রিয়ভাবে `views_count = views_count + 1` বৃদ্ধি পায়।
   - পড়ার আনুমানিক সময় হিসাব: `ceil(word_count / 180)` মিনিট রিড।
   - প্রতিটি পোস্টের জন্য আলাদা ভিজিটর ট্র্যাকিং: `trackVisit($pdo, 'article: slug')`।
৪. অ্যাডমিন পোস্ট ম্যানেজার (`admin/posts.php`, `create_post.php`, `edit_post.php`):
   - শিরোনাম, অটো-স্লাগ, ক্যাটাগরি, কভার ইমেজ ও পূর্ণাঙ্গ HTML কন্টেন্ট তৈরি ও সম্পাদনা।


================================================================================
৮. ফাইলের তালিকা ও ফাংশনভিত্তিক কোড বিশ্লেষণ (File & Function Breakdown)
================================================================================

📁 config/
   ├── database.php  : PDO দিয়ে PostgreSQL এর সাথে কানেকশন তৈরি ও এরর হ্যান্ডলিং।
   └── env.php       : .env ফাইল থেকে ডাটাবেস ক্রেডেনশিয়াল ও টোকেন লোড করে।

📁 includes/
   ├── functions.php :
   │     ├── ensureSchemaUpToDate() : স্বয়ংক্রিয় স্কিমা মাইগ্রেশন ও সিড ডেটা তৈরি।
   │     ├── getUserIP()            : ক্লায়েন্টের আসল IP শনাক্তকরণ।
   │     ├── isIpBlocked()          : আইপি ব্লক যাচাই।
   │     ├── blockIp() / unblockIp(): ফায়ারওয়াল ব্লকলিস্ট ম্যানেজমেন্ট।
   │     ├── parseUserAgent()       : ব্রাউজার, ওএস, ডিভাইস ও বট ডিটেকশন।
   │     └── getGeoData()           : ক্যাশিং সহ IP থেকে লোকেশন ও কোঅর্ডিনেট বের করা।
   │
   └── track.php     :
         └── trackVisit()           : প্রতিটি পেজ লোডে ফায়ারওয়াল চেক ও ভিজিট লগিং।

📁 public/
   ├── index.php     : ব্লগের হোমপেজ ও সার্চ।
   ├── blog.php      : সমস্ত আর্টিকেলের আর্কাইভ ও ক্যাটাগরি ভিউ।
   ├── post.php      : সিঙ্গেল পোস্ট রিডার পেজ (ভিউ কাউন্টার সহ)।
   ├── about.php     : প্ল্যাটফর্ম পরিচিতি।
   ├── contact.php   : যোগাযোগ ও মেসেজ ফর্ম।
   └── css/style.css : আধুনিক রেসপনসিভ ডিজাইন ও টাইপোগ্রাফি স্টাইল।

📁 admin/
   ├── dashboard.php : অ্যানালিটিক্স, মানচিত্র, চার্ট ও আইপি ব্যান ড্যাশবোর্ড।
   ├── api_live.php  : রিয়েল-টাইম AJAX অটো-রিফ্রেশ এন্ডপয়েন্ট।
   ├── login.php     : অ্যাডমিন সিকিউর লগইন (password_verify ও Auto-Fill সহ)।
   ├── logout.php    : অ্যাডমিন সেশন ধ্বংস করে লগআউট।
   ├── posts.php     : ব্লগের সব পোস্ট তালিকা ও ডিলিট অপশন।
   ├── create_post.php: নতুন ব্লগ লেখার ফর্ম।
   └── edit_post.php : বিদ্যমান ব্লগ পোস্ট এডিট করার ফর্ম।

📁 sql/
   └── schema.sql    : ডাটাবেস স্ট্রাকচার, ইনডেক্সিং ও ডিফল্ট অ্যাডমিন একাউন্ট।


================================================================================
৯. ডাটাবেস স্কিমা ও টেবিল ব্যাখ্যা (PostgreSQL Schema)
================================================================================

১. `visitor_logs` (ভিজিটর ট্র্যাকিং টেবিল):
   - id           : SERIAL PRIMARY KEY
   - ip_address   : INET NOT NULL (আইপি অ্যাড্রেস)
   - country, city, region, isp : লোকেশন ও ইন্টারনেট প্রোভাইডার
   - latitude, longitude        : মানচিত্রের অক্ষাংশ ও দ্রাঘিমাংশ (NUMERIC)
   - browser, os, device_type   : ব্রাউজার ও ডিভাইস
   - is_bot       : BOOLEAN (বট ট্রাফিক চিহ্নিতকারী)
   - page_visited : কোন পেজ বা আর্টিকেলে ঢুকেছে
   - visited_at   : ভিজিট করার সঠিক টাইমস্ট্যাম্প

২. `ip_geo_cache` (স্মার্ট জিওলোকেশন ক্যাশ):
   - ip_address   : INET PRIMARY KEY
   - country, city, region, isp, latitude, longitude
   - cached_at    : ক্যাশ করার তারিখ (৩০ দিন মেয়াদী)

৩. `blocked_ips` (ফায়ারওয়াল ব্লকলিস্ট):
   - id           : SERIAL PRIMARY KEY
   - ip_address   : INET UNIQUE NOT NULL (ব্লক করা আইপি)
   - reason       : ব্লক করার কারণ
   - blocked_at   : ব্লক করার তারিখ

৪. `posts` (ব্লগ আর্টিকেল টেবিল):
   - id           : SERIAL PRIMARY KEY
   - title        : ব্লগের শিরোনাম
   - slug         : ইউআরএল ফ্রেন্ডলি স্লাগ (UNIQUE INDEX)
   - excerpt      : ছোট সারাংশ
   - content      : মূল আর্টিকেলের বিষয়বস্তু
   - category     : ক্যাটাগরি (INDEXED)
   - image_url    : কভার ছবি
   - views_count  : মোট কতবার পড়া হয়েছে
   - created_at   : প্রকাশের তারিখ

৫. `admins` (অ্যাডমিন একাউন্ট টেবিল):
   - id           : SERIAL PRIMARY KEY
   - username     : admin
   - password_hash: password_hash('admin123', PASSWORD_DEFAULT)
   - created_at   : তৈরির তারিখ
